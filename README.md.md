### 📖 About the project

**Sergy OS** is an interactive personal portfolio inspired by the **Windows 11 desktop experience**.

Instead of using a traditional portfolio layout, the project presents my **projects, education, experience and skills through a simulated operating system interface**.

The goal is to create a more interactive and memorable way of exploring my professional background while demonstrating my frontend development skills.

### 🛠️ Technologies

**Frontend**

* **React** — Used to build the interactive desktop interface.
* **TypeScript** — Type-safe application development.
* **CSS** — Desktop layout, styling and responsive behavior.
* **Zustand** — Global state management for windows and desktop interactions.
* **React RND** — Draggable and resizable application windows.
* **DragSelect** — Desktop icon selection and interaction.
* **Fluent UI Icons** — Windows-inspired interface icons.
* **Motion** — Animations and UI transitions.

**Development**

* **Vite** — Development environment and build tool.
* **Git** — Version control.
* **GitHub** — Source code and project management.

### 🎨 Design & Development

The interface was designed from scratch with the goal of recreating the **visual language and interaction patterns of Windows 11** while adapting them to a personal portfolio.

The desktop includes:

* 🗂️ File Explorer-style navigation
* 🖥️ Interactive desktop
* 🪟 Draggable and resizable windows
* 📌 Taskbar
* 🔍 Start menu
* 📅 Calendar
* 🖱️ Desktop icon selection
* 📁 Portfolio content organized as files and folders

The project combines **UI/UX design, frontend development and interactive web experiences** into a single portfolio.

### 📖 About the project

**INMOFY** is a web application focused on **real estate property management and discovery**.

The platform allows users to browse properties, view detailed information, save properties and interact with a real estate-oriented interface.

The project was developed to practice **full-stack web development**, combining a modern frontend with a REST API backend and database persistence.

### 🛠️ Technologies

**Frontend**

* **Angular** — Used to build the web application and its user interface.
* **TypeScript** — Application logic and type-safe development.
* **RxJS** — Reactive programming and asynchronous data streams.
* **Angular Router** — Client-side navigation.
* **Reactive Forms** — Form creation and validation.
* **Angular Signals** — Reactive state management.
* **CSS** — Application styling and responsive layouts.

**Backend**

* **Spring Boot** — REST API development.
* **Java** — Backend application logic.
* **Spring Data JPA** — Data access and persistence.
* **Hibernate** — ORM and database communication.
* **MySQL** — Database.
* **Spring Security** — Authentication and authorization.
* **JWT** — Secure user authentication.

### 🎨 Design & Development

The application was designed around a **clean and modern real estate experience**, focusing on making property discovery and management straightforward for users.

The project includes:

* 🏠 Property listings
* 🔎 Property search
* 📋 Detailed property information
* ❤️ Saved properties
* 👤 User authentication
* 🔐 Protected resources
* 📱 Responsive interface
* 🌐 REST API communication

The project combines **Angular and Spring Boot** to demonstrate full-stack development, from the user interface to authentication, business logic and database persistence.
